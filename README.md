# Class 7 ICSE Maths Quiz

A browser-based, chapter-wise mathematics practice quiz for Class 7 ICSE.

## Features
- 13 syllabus chapters
- 50 practice questions per chapter (650 total)
- Easy, Moderate and Difficult levels
- Instant answer checking and explanations
- Runs in a browser; no installation or backend required

## Run locally
Open `index.html` in a modern web browser.

## Publish with GitHub Pages
1. Create a new **Public** repository on GitHub.
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.

## Note
The questions are original practice questions aligned to the listed Class 7 ICSE topics; they are not reproduced Selina textbook exercise questions.
